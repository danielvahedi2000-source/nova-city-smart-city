# NOVA CITY — Smart City Concept Website

A responsive, front-end concept website for a Smart City project, with a Marketing & Communication focus.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and demo contact form

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with Vercel
1. Create a GitHub repository and upload these three files to its root.
2. Sign in to Vercel using GitHub.
3. Select **Add New → Project**, import the repository.
4. Keep Framework Preset as **Other**; leave build/output settings at their defaults.
5. Click **Deploy**. Share the generated `*.vercel.app` URL.

## Project note
NOVA CITY is a fictional concept. The website describes proposed ideas, not real city infrastructure or verified performance statistics. The contact form is a front-end demo and does not send or store messages.
